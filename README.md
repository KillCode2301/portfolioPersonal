# Personal Portfolio

A modern personal portfolio website showcasing projects, experience, and contact information.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## Getting Started

```sh
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```

## Scripts

- `bun run dev` - Start development server
- `bun run build` - Build for production
- `bun run preview` - Preview production build
- `bun run lint` - Run ESLint
